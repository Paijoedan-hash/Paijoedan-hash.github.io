Kalkulator Kalori Schofield

Menghitung Basal Metabolic Rate (BMR) berdasarkan persamaan Schofield.
Sumber: Schofield WN. Hum Nutr Clin Nutr 1985; 39C Suppl 1:5-41 | nafwa.org

Input

Rumus Schofield (W=berat kg, H=tinggi cm)

Laki-laki:
<3 th: 0.167W + 15.174H − 617.6
3-10 th: 19.59W + 1.303H + 414.9
10-18 th: 16.25W + 1.372H + 515.5
18-30 th: 15.057W − 0.1H + 705.8

Perempuan:
<3 th: 16.252W + 10.232H − 413.5
3-10 th: 16.969W + 1.618H + 371.2
10-18 th: 8.365W + 4.65H + 200.0
18-30 th: 13.623W + 2.83H + 98.2

Hasil

Masukkan data, lalu klik Hitung BMR.
